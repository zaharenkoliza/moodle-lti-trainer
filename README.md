# LTI-тренажёр для Moodle

Исходники тренажёра курса «Веб-технологии: JavaScript и HTTP». Три вопроса по JavaScript, HTTP и голосовому интерфейсу оцениваются в 3, 3 и 4 балла. Оценка передаётся в журнал Moodle через LTI 1.1 Basic Outcomes.

## Адреса

- `/lti/launch` — подписанный запуск из Moodle;
- `/trainer` — тренажёр после запуска;
- `/api/submit` — проверка ответов и передача оценки;
- `/healthz` — состояние сервиса.

## Настройка

Для LTI нужны переменные окружения `LTI_CONSUMER_KEY`, `LTI_SHARED_SECRET` и `SESSION_SECRET`. Значения не входят в репозиторий. Укажите в Moodle внешний HTTPS-адрес сервиса с путём `/lti/launch`, LTI 1.0/1.1 и приём оценок. Адрес Moodle для передачи оценок задан константой `MOODLE` в `worker/index.js`.

Прямой переход на `/trainer` не создаёт сеанс. Для локальной проверки: `npm test`, `npm run build`, `npm run validate`.

Это выделенные исходники тренажёра из общего проекта; рабочий сайт может размещать тренажёр и таблицу оценок вместе.
